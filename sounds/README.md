# Optional recorded boom sounds

Drop **royalty-free** (or your own) explosion recordings here, named:

    boom1.mp3  boom2.mp3  boom3.mp3  boom4.mp3

Then enable **Settings → Sound → "Use recordings from /sounds"**. Booms will use the
recordings (random pick, slight pitch variation, distance filtering) instead of the
synthesized boom. Serve the folder over http(s) (e.g. `python3 -m http.server`);
browsers block `fetch` from `file://`.

Only add audio you have the right to use.
